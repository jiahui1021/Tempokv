# Self-Forcing innovation ablation

This small paired run compares three V predictors with every other setting held
fixed:

| Variant | V source | `VH` |
| --- | --- | ---: |
| `temporal_vh1` | reconstructed V history | 1 |
| `cross_temporal_vh1` | reconstructed K + reconstructed V history | 1 |
| `innovation_temporal_vh1` | decoder-visible K innovation + reconstructed V history | 1 |

The default is one 105-frame generation per selected prompt. This is the
smallest valid Self-Forcing length that reaches 27 latent frames and therefore
actually triggers TempoKV. All variants use the same calibration trace, prompt
range, seed, K/V bit width, K history, frame count, and `layer_shared` source
projection. BF16 is generated by default and used as the paired quality
reference.

```bash
CHECKPOINT=/models/self_forcing_dmd.pt \
WAN_MODEL_DIR=/models/Wan2.1-T2V-1.3B \
PROMPTS=assets/generation_prompts.txt \
bash scripts/Self-Forcing/run_innovation_ablation.sh
```

Useful controls are `TRACE_FILE`, `OUTPUT_ROOT`, `FRAMES`, `SEED`,
`START_INDEX`, `END_INDEX`, `BITS`, `KH`, `INCLUDE_BF16`, `RUN_QUALITY`,
`QUALITY_FID`, `MAX_QUALITY_FRAMES`, and `RESUME`.

Set `DRY_RUN=1` to validate and record the complete command matrix without
fitting or generating. The output root always contains machine-readable
`manifest.json` and `summary.json`. Paired PSNR, SSIM, and LPIPS reports are
stored under `quality/`; FID is disabled unless `QUALITY_FID=1`. If quality
dependencies or the BF16 reference are unavailable, the summary records
`quality_status: not_run` and does not invent metric values.
