# Self-Forcing predictor ablation: 60 prompts

`run.py` runs the new predictor groups on the first 60 prompt lines in
`assets/moviegen128.txt`. It schedules four Self-Forcing generation processes
at once, assigning one GPU to each process:

| Group | V predictor | History |
| --- | --- | ---: |
| `learned_temporal_vh2` | learned temporal | 2 |
| `identity_vh2` | fixed `V_t = V_{t-1}` | 2 |
| `taylor_vh2` | fixed `V_t = 2V_{t-1} - V_{t-2}` | 2 |
| `taylor2_vh3` | fixed `V_t = 3V_{t-1} - 3V_{t-2} + V_{t-3}` | 3 |

BF16 and the existing production TempoKV videos are never generated by this
script. Their existing `videos` directories are passed as metric references.
Quality workers start after the four generation jobs finish; each worker reads
video frames incrementally, writes one CSV row after every completed video, and
updates its JSON report atomically. The default metrics are RGB PSNR, SSIM and
LPIPS. Add `--quality-fid` when FID is needed.

```bash
python scripts/paper_experiments/predictor_ablation/run.py \
  --checkpoint /models/self_forcing_dmd.pt \
  --wan-model-dir /models/Wan2.1-T2V-1.3B \
  --trace data/self-forcing/trace/clean_trace.npz \
  --bf16-videos results/self_forcing/bf16/videos \
  --tempokv-videos results/self_forcing/legacy-kh2-vh1-int4-layershared/videos \
  --output-root results/self_forcing/predictor_ablation_60p \
  --gpus 0,1,2,3
```

The defaults use `configs/legacy.json`, the bit widths in that config, 717
video frames, seed 0, and `fit_history_source=reconstructed`. Use
`--resume` after an interrupted run. Use `--dry-run` to write the complete
four-GPU command matrix without requiring the checkpoint, model directory, or
reference video directories.

Outputs:

```text
<output-root>/manifest.json
<output-root>/summary.json
<output-root>/summary.csv
<output-root>/configs/<variant>.json
<output-root>/params/<variant>/
<output-root>/runs/<variant>/videos/
<output-root>/quality/<variant>/vs_bf16.{csv,json}
<output-root>/quality/<variant>/vs_tempokv.{csv,json}
```

Use `--no-quality` when only the predictor videos are needed. In that mode the
BF16 and TempoKV reference directories can be omitted.
